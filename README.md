# Diplom_3

UI-автотесты для Stellar Burgers на Python в рамках дипломного проекта Яндекс.Практикума.

Стек:
- `Python 3`
- `pytest`
- `Selenium WebDriver`
- `webdriver-manager`
- `requests`
- `allure-pytest`

Что реализовано:
- `Page Object` для основных экранов и модальных окон.
- Запуск одинаковых тестов в `Google Chrome` и `Mozilla Firefox`.
- `Allure`-отчёт со скриншотом и HTML страницы при падении теста.
- API-предусловия для создания и удаления тестового пользователя.

Покрытые проверки:
- переход по клику на `Конструктор`;
- переход по клику на `Лента заказов`;
- открытие модального окна по клику на ингредиент;
- закрытие модального окна по крестику;
- увеличение счётчика ингредиента после добавления в заказ;
- рост счётчиков `Выполнено за всё время` и `Выполнено за сегодня` после оформления заказа;
- появление номера заказа в блоке `В работе`.

Структура проекта:
- `pages` - page objects;
- `tests` - UI-тесты;
- `config.py` - константы проекта;
- `browser_utils.py` - браузеры и вложения `Allure`;
- `user_api.py` - генерация и API-операции с тестовым пользователем;
- `conftest.py` - фикстуры, параметризация браузеров и обработка падений.

Установка зависимостей:

```bash
pip install -r requirements.txt
```

Запуск тестов:

```bash
pytest
```

Headless-режим:

```bash
pytest --headless
```

Запуск только в одном браузере:

```bash
pytest --browser chrome
pytest --browser firefox
```

Генерация Allure-отчёта:

```bash
pytest --alluredir=allure_results
allure serve allure_results
```
